# Toaster / Toast

An opinionated, elegant toast notification component built upon Sonner and fully integrated with `@yuva-devlab/tokens` CSS variables.

Defaults to `bottom-right` positioning with a subtle dark/light card surface and isolated semantic feedback icons (`success`, `error`, `warning`, `info`).
